# Überprüfen des Speicherplatzlimits für Adobe Commerce in der Cloud-Infrastruktur

So überprüfen Sie, wie viel Speicherplatz Sie für jede Adobe Commerce in der Cloud-Infrastrukturumgebung haben:

1. Melden Sie sich bei der [Cloud-Konsole](https://console.adobecommerce.com/) an.
2. Wählen **im Dashboard** Alle Projekte“ das entsprechende Projekt aus. Siehe Verfügbarer Speicherplatz in der unteren Ecke.

[Projektbereich](/help/assets/disk-space.png)

## Verwandtes Lesen

[Verwalten des Festplattenspeichers](https://experienceleague.adobe.com/en/docs/commerce-on-cloud/user-guide/develop/storage/manage-disk-space?lang=en) in unserer Entwicklerdokumentation.
