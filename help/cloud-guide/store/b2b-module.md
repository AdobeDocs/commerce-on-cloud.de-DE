# B2B-Modul aktivieren

Wenn Ihre Kunden Unternehmen sind, können Sie das Adobe Commerce B2B-Modul installieren, um Ihr Adobe Commerce on Cloud Infrastructure Pro-Projekt zu erweitern und so ein Business-to-Business-Modell aufzunehmen. Informationen zum Installieren und Konfigurieren des B2B-Moduls für Adobe Commerce in Cloud-Infrastrukturen finden Sie im [Adobe Commerce B2B-Benutzerhandbuch](https://experienceleague.adobe.com/en/docs/commerce-admin/b2b/guide-overview).
